# Steam Frame Controls

These are the default NomaiVR controls for the Steam Frame controllers. The input prompts on your hand always show the current button for an action, so use them when in doubt. Motion controls like the tool belt and the flashlight gesture are described in [VR Gestures](VR_GESTURES.md).

If the controls feel scrambled, SteamVR is probably using an emulated Oculus Touch binding. Reset the bindings for Outer Wilds in SteamVR so it uses the NomaiVR default binding for the Frame controller.

## On foot

| Action | Button |
|---|---|
| Move | Left stick |
| Turn | Right stick (snap turning can be enabled in the mod settings) |
| Jump / jetpack boost | Right **A** |
| Jetpack up | Right trigger |
| Jetpack down | Left trigger |
| Interact (talk, pick up, use) | Right **X**, while pointing the laser at the object |
| Secondary interact | Bumper (either hand) |
| Back | Right **B** |
| Pause menu | Right **Menu** |
| Map | Left stick click |
| Roll mode (zero gravity) | Hold grip |
| Recenter VR | Left **View** |

## Menus

| Action | Button |
|---|---|
| Point | Laser from your dominant hand |
| Select | Right trigger or right **X** |
| Back | Right **B** |
| Navigate | Left stick |
| Switch tabs | Touch the right stick left / right |
| Switch sub-tabs | Touch the right stick up / down |

## Handheld tools (scout launcher, signalscope, translator)

Take a tool from the [tool belt](VR_GESTURES.md#tool-belt) by holding grip. While you hold it:

| Action | Button |
|---|---|
| Use (launch the scout, toggle the signalscope zoom lens, …) | **Squeeze the grip fully** on the hand holding the tool |
| Tool secondary | Bumper on the hand holding the tool |
| Tool directions (see the prompts on your hand) | Tool in the left hand: **d-pad**. Tool in the right hand: **Y** up, **A** down, **X** left, **B** right |

While a tool is in your right hand, A, B and X are tool directions, so jump, back and interact aren't available until you put it away.

## Ship

| Action | Button |
|---|---|
| Thrust | Left stick |
| Rotate | Right stick |
| Thrust up / down | Right trigger / left trigger |
| Roll mode | Hold grip |
| Match velocity | Right **A** |
| Autopilot | Right stick click |
| Map | Left stick click |
| Interact (cockpit screens and buttons, with the laser) | Right **X** |

While the ship scout or signalscope is active, the controls are the same for left- and right-handed players:

| Action | Button |
|---|---|
| Launch / use | Right bumper |
| Tool secondary | Left bumper |
| Tool directions | Left d-pad |
